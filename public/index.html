    OCR TEXT

    For a Firefox add-on

    Every character is a real DOM element, so an add-on can find and read it. Tap mode keeps the overlay transparent (scrolling always wins); read mode draws the text so you can select it.

    A ready-to-load add-on is included — download it, then in Firefox open about:debugging → This Firefox → Load Temporary Add-on → pick the manifest.json.

    manifest.json · manga-cab-reader.js

    From the add-on console:

    MANGA_CAB.hitTest(x, y)   // char under a point
MANGA_CAB.getCharacters()   // every char + rect
MANGA_CAB.getLines()        // every OCR section
MANGA_CAB.getTranscript()   // whole volume, by page

    Each character also carries data-ocr-char, data-ocr-page and data-ocr-line, so a plain document.elementFromPoint() works in read mode.
